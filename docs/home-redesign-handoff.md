# تحویل بازطراحی «خانه من»

مبنا: `d9a9e61431ebd78fec658cfd9b4fe145039f973d`؛ شاخه مستقل `work/home-redesign`.

## تغییرات محدود به خانه

- چیدمان RTL بر مبنای تصویر اول: زمینه آبی بسیار روشن، کارت‌های سفید و رنگ‌های ملایم، نوار کوه و طلوع، سه شاخص، اولویت‌ها، برنامه بعدی، اعلان مهم و چهار میانبر.
- خلاصه خانه سه اولویت مهم واقعی را نشان می‌دهد؛ این تعداد زیر سقف پنج مورد در درخواست است و با چیدمان مرجع و هدف یک ارتفاع هماهنگ است. تمام کارها از «مشاهده همه» قابل دسترسی‌اند؛ هیچ رکوردی حذف یا در منبع داده پنهان نشده است.
- فهرست تماس‌ها، انجام‌شده‌ها، برنامه‌ها و تأییدهای تکراری از خانه برداشته شد. آمار از همان `workSummary` و دسترسی مرکزی می‌آید.
- برنامه بعدی از کار/برنامه واقعی مجاز انتخاب می‌شود و با موارد نمایش‌داده‌شده در اولویت‌ها تکراری نیست. در نبود داده، حالت خالی نمایش داده می‌شود.
- اعلان مهم، آخرین اعلان ذخیره‌شده، مجاز و خوانده‌نشده برای همان گیرنده است. شمارش زنگ از API موجود اعلان‌هاست و در حالت صفر نشانگر رنگی ندارد.
- پاکت، فهرست مکاتبات داخلی واقعاً مرتبط با کاربر را باز می‌کند و به `/work/mail?id=...` می‌رود. وضعیت خوانده‌شدن پیام داخلی در ساختار فعلی وجود ندارد؛ برای پاکت عدد خوانده‌نشده ساخته نشده و این محدودیت داخل فهرست هم نوشته شده است. پیام‌رسان جدید یا جدول جدید ایجاد نشده است.
- جست‌وجو از سوابق مجاز API فعلی کارتابل و جست‌وجوی `q` در API فعلی عملیات استفاده می‌کند؛ نتیجه به رکورد واقعی می‌رود. این قابلیت جست‌وجوی کامل همه پایگاه‌های مالی/فایل‌ها نیست؛ عنوان فهرست دامنه را روشن می‌کند.
- ساختار، نام گروه‌ها، مسیرها و مجوزهای سایدبار همان نسخه فعلی‌اند؛ از منوی اشتباه تصویر اول کپی نشده‌اند. رنگ‌بندی سرمه‌ای فقط روی مسیر خانه اعمال می‌شود و اسکرول سایدبار مستقل است.
- نام، سمت، آواتار حرفی و اطلاعات صفحه از حساب واقعی‌اند؛ نام، عکس شخص، تعداد و قرار نمونه مرجع در محصول ثابت نشده‌اند. پیام انگیزشی از مجموعه داخلی موجود روزانه انتخاب می‌شود؛ فراخوانی AI روزانه وجود ندارد.
- تصویر پایین صفحه تزئینی و فقط در ارتفاع کافی دسکتاپ نمایش داده می‌شود. تصاویر کوه و ساختمان به شکل asset واقعی همراه سورس‌اند.

باز/بسته‌شدن منوی تبلت و موبایل، ثابت‌ماندن عرض و جایگاه خانه با بازشدن گروه‌های منو، دریافت واقعی نتایج جست‌وجو، دو فهرست مستقل زنگ و پاکت، مقصد لینک‌ها، عدم شمارش ساختگی مکاتبات، حالت خالی و جداسازی اطلاعات یک کارمند دیگر آزمایش شدند. هیچ خطای JavaScript صفحه ثبت نشد. عکس‌ها و `metrics.json` در پوشه screenshots بسته تحویل‌اند؛ اطلاعات آن‌ها صرفاً داده آزمون محلی است.

## اعمال Patch در Work

از پروژه موجود با commit مبنا استفاده کنید؛ پروژه تازه لازم نیست:

```sh
git switch -c work/home-redesign d9a9e61
git apply --check /path/to/SYNAPSE-home.patch
git apply /path/to/SYNAPSE-home.patch
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
pnpm build
```

در صورت استفاده از ZIP سورس کامل، پوشه SYNAPSE را در Work باز کنید و همان دستورهای نصب/بررسی را اجرا کنید. فایل‌های محیطی و secrets خود را حفظ کنید؛ داخل ZIP secrets قرار ندارد.

این تغییر بر مبنای نسخه d9a9e61 است و **Migration جدیدی ندارد**. پیش‌نیازهای همان نسخه، از جمله Migration ۱۷ در محیط مقصد، همچنان لازم‌اند. به main یا سایت زنده اعمال نشده و هیچ push، انتشار، تغییر داده اصلی یا تنظیم محرمانه انجام نشده است.

آزمون مرورگر محلی:

```sh
node scripts/test-home-browser.mjs
```

اسکریپت از Playwright و Chromium موجود محیط استفاده می‌کند؛ در محیط متفاوت `PLAYWRIGHT_MODULE` و `CHROMIUM_PATH` را به نصب محلی خود اشاره دهید. fixtures فقط در حافظه ساخته و در پایان از بین می‌روند. برای بازگشت، شاخه مبنا را باز کنید؛ چون داده یا schema تغییر نکرده، بازگشت دیتابیس لازم نیست.
