# قوانین مصوب SYNAPSE

تاریخ: ۱۴۰۵/۰۸/۱۸ — 2026-11-09

1. تعیین هرگونه سقف مصرف یا توقف کار بر اساس سهمیه توسط دستیار، تا دستور جدید مالک ممنوع است. این دستور محدودیت‌های خود سرویس ChatGPT را تغییر نمی‌دهد.
2. بخش «عملیات و مشتریان» شامل پذیرش، تیکت، تماس ورودی، ارتباط خروجی و مراجعات، از نظر نمایش منو برای حساب‌های فعال باز است؛ طبق دستور مرحله اول گردش کار در ۲۰۲۶/۱۱/۱۴، مشاهده داده در API نیازمند مجوز دسته و مسئولیت یا ثبت‌کنندگی همان پرونده است. حساب آزمایشگاه به اطلاعات عملیات عمومی دسترسی ندارد. اطلاعات محرمانه مدیریت، بانک و مجوزهای مستقل مالی و علمی مستقل باقی می‌مانند.
3. کارکنان مجاز به ایجاد دستور یا وظیفه برای خود نیستند. ایجاد و ارجاع کارتابل با مدیریت است؛ مدیران غیر از مالک اصلی نیز نمی‌توانند کار جدید را به خود ارجاع دهند. گزارش، تکمیل و ویرایش کار قبلاً ارجاع‌شده مجاز می‌ماند. ثبت تماس یا درخواست مشتری بدون مسئول ممکن است.
4. حذف سوابق فقط برای حساب اصلی مالک مجاز است؛ نقش مدیریت به‌تنهایی مجوز حذف نمی‌دهد.

سوابق قدیمی خودارجاع حذف نمی‌شوند؛ برای تصمیم مدیریت حفظ می‌شوند.

5. مدیریت مصرف: پاسخ کوتاه، ابزار فقط در صورت نیاز؛ عملیات اجرایی پس از اعلام برآورد مصرف (یا نامشخص‌بودن عدد دقیق) و تأیید مالک. از تعیین سهمیه فرضی، تست تکراری و انتشار غیرضروری خودداری شود.
